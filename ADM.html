⚙️ Firebase ainda não configurado

O painel precisa do Firebase (Firestore + Authentication) para salvar inscrições, resultados e configurações para todos os visitantes.

  1. Crie um projeto grátis em console.firebase.google.com.
  2. Ative Authentication → E-mail/senha e crie o usuário administrador.
  3. Ative o Firestore Database e publique as regras do arquivo firestore.rules.
  4. Cole a configuração do app web em firebase-config.js.

Passo a passo completo: FIREBASE_SETUP.md. Enquanto isso, o site funciona com os dados padrão.
